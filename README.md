#  Proyecto Instalador Automatizado de Paquetes en Terminal --Debian 13

Script quebne lee una lista de paquetes desde  un archivo de texto y los instala con apt, verificando dependencias y registrando exitos y fallos en un achivo de log.Es util para el aprovisionamiento de entornos 

Desarrolado y probado sobre Debian 13 usando visual studio code dentro la maquina virtual
